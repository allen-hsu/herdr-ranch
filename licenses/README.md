# Third-party origins

Two mods started as copies of open-source Herdr mods and are now maintained here; four more are edited
clones of mods that ship with Herdr.
Their original licenses still apply to the parts that came from them.

| Mod | Started from | License |
|---|---|---|
| `mods/space-folders` | jankeesvw/herdr-space-folders (cloned from Herdr's `spaces` 0.1.10) | MIT or Apache-2.0 (`space-folders-*.txt`) |
| `mods/git-graph` | rabeeh-ta/herdr-git-graph | MIT (`git-graph-MIT.txt`) |
| `lib/folders.js` | folder matching ported from jankeesvw/herdr-space-folders @63a78b2 | MIT |
| `mods/changes-plus`, `mods/agents-ctx`, `mods/tabs-plus`, `mods/files-plus` (and the Herdr-derived part of `mods/space-folders`) | clones of Herdr's shipped `changes` 0.1.14 / `agents` 0.1.14 / `tabs` / `files` (and `spaces` 0.1.10) | not established: no license text for Herdr's mods is included here; check Herdr's terms before redistributing |
| `lib/icons/*.svg`, `lib/team.svg`, `lib/more.svg`, `lib/folder-open.svg`, most of `mods/git-graph/icons` | Lucide icons (lucide.dev) | ISC (`lucide-ISC.txt`) |
